# FounderOS Mobile PWA v1.0

A mobile-first, installable PWA for managing an AI-first app-development startup workflow.

## Files
- `index.html` — the app
- `manifest.json` — install metadata
- `service-worker.js` — offline caching
- `icons/` — PWA icons

## Deploy
Upload the full folder contents to GitHub Pages or any static web host. Open the site on iPhone Safari, then use Share → Add to Home Screen.

## Data
Data is stored locally in the browser using `localStorage`. Use Export JSON regularly for backups.
